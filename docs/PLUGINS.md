# Plugins & Library Integration Architecture

## 1. Backend Geospatial Processing Libraries

### 1.1 `earthaccess`
- **Role:** Direct access and cloud-streaming retrieval of NASA Earthdata assets.
- **Integration:** Authenticates via `EARTHDATA_TOKEN` (or netrc) and facilitates subset streaming from DAAC cloud object storage without requiring full multi-gigabyte zip downloads.

### 1.2 `rioxarray` & `xarray`
- **Role:** High-performance multidimensional raster manipulation and projection alignment.
- **Key Method:** `after_da.rio.reproject_match(before_da)`
  - Re-projects disparate Coordinate Reference Systems (e.g. UTM zones vs. WGS84 EPSG:4326).
  - Aligns pixel grid bounds, cell dimensions, and nodata masks so array element operations $(i, j)$ map to the identical geographic coordinates.

### 1.3 `h5py` & `rasterio`
- **Role:** Native reader for NISAR Level-2 GCOV (Geocoded Backscatter) and GUNW (Geocoded Unwrapped Interferogram) HDF5 products and Sentinel-1 GeoTIFFs.
- **NISAR HDF5 Hierarchy:**
  - Standard path: `/science/LSAR/GCOV/grids/frequencyB/HHHH` or `/frequencyA/HHHH`
  - Radiometric datasets: Extract backscatter matrix, metadata affine transformation coefficients, and projection WKT.

### 1.4 `shapely` & `geopandas`
- **Role:** High-precision vectorization and geodesic area computation.
- **Workflow:**
  1. Extract raster contour polygons from binary numpy mask via `rasterio.features.shapes`.
  2. Load into `geopandas.GeoDataFrame`.
  3. Re-project to an equal-area projection (e.g., EPSG:6933 Equal Area Cylindrical or Local UTM) to calculate exact, physically verified $km^2$ unaffected by high-latitude mercator distortion.
  4. Export valid GeoJSON feature collection for Leaflet rendering.

### 1.5 `xsar` (Optional S1 Extension)
- **Role:** Specialized Sentinel-1 radiometric calibration and ground range antenna pattern normalization.

## 2. Frontend Leaflet Cartographic Plugins

### 2.1 `@geoman-io/leaflet-geoman-free`
- **Role:** Interactive geometry editing and drawing suite on Leaflet maps.
- **Features Activated:**
  - Polygon and Rectangle drawing tools for mission AOI definition.
  - Coordinate extraction converting drawn vector layers directly into WKT strings for backend transmission.
  - Global styling override matching the Brown & Beige theme (`#4A3525` stroke, `#EAE0D0` handles).

### 2.2 `leaflet-side-by-side`
- **Role:** Split-screen Before/After swipe curtain.
- **Functionality:** Partitions map container into left and right viewports separated by an interactive vertical divider handle.
- **Visual Mapping:**
  - Left pane: Pre-event baseline SAR backscatter tile / browse layer.
  - Right pane: Post-event SAR layer with Terracotta change mask overlay.

### 2.3 `leaflet-control-geocoder`
- **Role:** Instant location search and place name geocoding.
- **Configuration:** Integrated directly with Nominatim OSM geocoding API, styled with `#FDFBF7` input box and sandstone borders.

### 2.4 `leaflet-compass`
- **Role:** Visual HUD navigational rose.
- **Styling:** Top-right corner mounting, `#4A3525` compass needle with real-time heading readout in `JetBrains Mono`.

## 3. Developer & Verification Plugins

### 3.1 `ruff`
- **Role:** High-speed Python linter and formatter configured in `/backend/pyproject.toml`.
- **Target Standards:** Python 3.10+, PEP 8 compliance, pyflakes, and bugbear rules.

### 3.2 Visual Studio Code Extensions (`/.vscode/extensions.json`)
- `charliermarsh.ruff`: Instant in-editor linting and automatic import sorting.
- `qwtel.sqlite-viewer`: Visual inspection of local `nisar_pulse.db` tables directly inside VS Code without external database GUI tools.

### 3.3 External QGIS Verification — NISAR Processor (Plugin ID: 6335)
- For field validation and independent ground-truthing, exported GeoTIFF and GeoJSON masks generated by NISAR-Pulse can be cross-verified directly in QGIS using the official **NISAR Processor plugin (Plugin ID: 6335)**.
- Provides standard polarimetric decomposition and interferometric baseline validation.
